CardBusiness

Este é um projeto desenvolvido em sala de aula para fins academicos.

Processo de desenvolvimento: 
Aula 01 - Criação da interface
Primeiramente, todo o foco foi em construir a parte visual do aplicativo.

Aula 02 - Integração com ViewModel
Com a tela prontas, a segunda etapa foi aplicar a arquitetura usando `ViewModel`. 
Essa mudança foi feita para separar a lógica de negócios da interface do usuário, garantindo que os dados do aplicativo fiquem seguros
e não sejam perdidos em mudanças de configuração (como quando o usuário gira a tela do celular).
